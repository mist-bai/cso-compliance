# 原型对照与开发计划

参考：`marketing-platform`（Next.js + FastAPI + MySQL）

## 门户映射

| 原型 | 本系统路径 | 状态 |
|------|------------|------|
| 角色首页 | `/` | 已实现 |
| 代理商入口 | `/agent` | 备案/拜访/会议/报告已接通 API |
| 代表入口 | `/rep` | 待办/备案/拜访/会议已接通 |
| 合规看板 | `/dashboard` | 服务商驾驶舱摘要 |
| 后台管理 | `/admin` | 代理商/服务商/产品/费用/报告/审批 |
| 课程管理 | `/courses` | 占位，后续对接誉学院 |

## 备案状态机

`已申请待考试` → `考试通过待备案` → `备案有效` / `备案撤销`
