# 原型对照与开发计划

原型：https://mimk44rm0t03.meoo.pub  
参考：`marketing-platform`（Next.js + FastAPI + MySQL）

## 门户映射

| 原型 | 本系统路径 | 状态 |
|------|------------|------|
| 角色首页 | `/` | 已实现 |
| 代理商入口 | `/agent` | 备案编辑/拜访下钻/会议申请修改总结/培训/报告 |
| 代表入口 | `/rep` | 待办/备案/拜访/会议总结/培训考试 |
| 合规看板 | `/dashboard` | 图表 + 服务商/代表/会议/培训明细 |
| 后台管理 | `/admin` | 主数据同步、医院导入、费用、报告、审批、备案推进 |
| 课程管理 | `/courses` | 课程创建 + 题目维护 + 参与统计 |

## 备案状态机

`已申请待考试` → `考试通过待备案` → `备案有效` / `备案撤销`
