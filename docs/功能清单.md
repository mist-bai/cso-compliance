## 二、按业务模块

### 1. 登录与权限
- JWT 登录（表单 / JSON）
- 角色 RBAC：admin / agent / rep / compliance / academy
- 账号停用后无法登录（代理商/代表启停会同步用户状态）

### 2. 主数据
- **工厂**：12 家法人工厂（问数 organizations）
- **服务商**：大连博道 / 天津博达 / 安徽博鑫 / 北京塞升；后台可新增
- **产品**：拜访产品大类；后台可新增
- **医院终端**：resources 抽样约 100 家 + 新增/CSV 批量导入
- **费用标准**：列表 + 后台新增
- **同步**：`POST /api/master/sync` 幂等同步 resources

### 3. 代表备案（状态机）
`已申请待考试` → `考试通过待备案` → `备案有效` / `备案撤销`

| 能力 | 谁做 |
|------|------|
| 新增备案（可选开通代表登录账号） | 代理商 |
| 编辑有效期/备注 | 代理商 |
| 搜索姓名/身份证、按工厂筛选 | 代理商 |
| 考试通过 / 确认备案 / 撤销 | 后台 |
| 备案考试通过自动推进状态 | 代表交卷触发 |

### 4. 代表拜访
- 代表提交拜访：**必须选择医院终端**，写入单次明细
- 月度汇总（目标 3 次）+ 完成率
- 代理商查看拜访列表、按次数下钻医院明细
- 服务商筛选可过滤拜访

### 5. 学术会议
流程：`计划中` → `待审批` → `已批准` → 提交总结 → `已完成`（可驳回）

| 能力 | 说明 |
|------|------|
| 申请会议 | 类型/地点/日期/参会人/事由；可选费用标准带出预算 |
| 修改申请 | 未完成前可改 |
| 提交审批 / 批准 / 驳回 | 代理商提交，后台或合规审批 |
| 提交总结 | 代理商或主责代表 |
| 详情弹层 | 参会人、预算、状态、总结 |
| 搜索 | 会议名/地点、参与代表 |

### 6. 培训考试
- 课程创建、编辑正文/开关、维护题目（增删）
- 代表：报名 → 学习 → 考试交卷
- **备案考试**课程：通过后同步备案为「考试通过待备案」
- 代理商：代表培训进度 +「查看明细」（课程/成绩）
- 课程端：参与统计、代表培训情况

### 7. 合规报告
- 代理商提交报告、查看详情
- 已驳回可修改后重新提交
- 后台：通过 / 驳回

### 8. 合规看板
- 摘要指标：代表数、备案、有效备案、拜访、会议、待考试
- 条形图：拜访周期、会议状态、备案状态、培训完成
- Tab：服务商驾驶舱（季度+关键字筛选）/ 代表监控 / 会议看板 / 培训统计
- 待培训人数为真实计算

### 9. 组织与账号管理（后台）
- 代理商：新增（含登录账号）、启用/停用
- 服务商：列表 + 新增
- 代表：列表启停 + 备案状态推进
- 工厂 / 产品 / 医院 / 费用 / 报告 / 会议审批

## 三、建议演示路径

1. **备案→考试→确认**  
   `agent_huabei` 新增备案并开号 → `rep_*` 做备案考试（选项全选 B）→ `admin` 确认备案

2. **拜访挂医院**  
   `rep_luohao` 待办选医院提交 → `agent_huabei` 代表拜访点次数看明细

3. **会议全流程**  
   `agent_huabei` 申请（选费用标准）并提交 → `admin` 批准 → 代理商/代表提交总结

4. **报告驳回重提**  
   代理商提交报告 → `admin` 驳回 → 代理商「重新提交」

5. **看板**  
   `compliance` 看各 Tab 图表与明细，试季度筛选
