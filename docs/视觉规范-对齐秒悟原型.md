# 视觉规范（对齐秒悟原型）

采样自 https://mimk44rm0t03.meoo.pub （shadcn light theme）

## 令牌

| 令牌 | 值 | 用途 |
|------|-----|------|
| background | `#ffffff` | 页面底 |
| foreground | `#0f172a` | 主文字 |
| muted | `#f1f5f9` | Tabs 轨道、图标底 |
| muted-foreground | `#64748b` | 次要文字 |
| primary | `#0f172a` | 主按钮（深色） |
| border | `#e2e8f0` | 边框 |
| radius | `0.625rem` | 卡片/控件圆角 |

## 组件

- **首页卡片**：白底、细边框、轻阴影；图标在浅灰圆角底，非实心黑块
- **Tabs**：`bg-muted` 轨道 + 激活项白底阴影（非深色 pill）
- **主按钮**：深色 primary + 白字
- **表格**：表头 muted 文字，细横线分隔
- **状态 Badge**：圆角色块（绿/黄/红/蓝）
- **字体**：PingFang SC / Microsoft YaHei 系统栈

实现落点：`frontend/app/globals.css`、`components/AppShell.tsx`、`components/ui.tsx`
